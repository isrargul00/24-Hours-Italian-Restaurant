## Project Overview

This project presents a customer-facing website concept for an Italian restaurant. It combines a lightweight Flask backend with responsive frontend templates and reusable static assets.

The solution is designed to help a local restaurant communicate its brand, display food and pricing, publish opening hours, provide location and contact information, and guide visitors toward reservations or enquiries.

## Key Features

- Responsive restaurant landing page
- Food menu and pricing presentation
- About and brand-story sections
- Opening-hours display
- Contact and location page
- Reservation-focused calls to action
- Food gallery and promotional sections
- Reusable Flask/Jinja templates
- Mobile-friendly Bootstrap layout

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/isrargul00/24-Hours-Italian-Restaurant.git
cd 24-Hours-Italian-Restaurant
```

2. Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows:

```powershell
.venv\Scripts\activate
```

3. Install dependencies and start the app:

```bash
pip install -r requirements.txt
python __init__.py
```

4. Open `http://127.0.0.1:5000` in your browser.
